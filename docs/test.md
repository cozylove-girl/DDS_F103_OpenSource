## 2026-06-15 更新说明

以上数据为旧版调理板实测原始记录，继续保留，不按新版硬件方案反向修改。

当前解释：

1. 固定 1MHz 时，OPA690 输出从 256mVpp 增加到 1420mVpp，而两个 AD8307 输出仅增加约 80mV，
   明显低于理想的 25mV/dB 斜率，说明旧板在该条件下存在明显顶部压缩或输出负载限制。
2. 两个通道输出几乎相同，不符合“OPA690 串联 50Ω + DUT 端 50Ω 对地终端”应产生约 2:1 电压
   关系的简单预期，旧板的终端焊接、真实测量节点和输入结构需要重新确认。
3. 新版方案改为两个 AD8307 均使用 5V 供电，REF/DUT 输入和输出结构保持对称，默认不安装固定
   50Ω 对地终端。
4. 新版实测时应优先检查输入幅度翻倍后 AD8307 输出是否增加约 150mV，而不是只判断输出是否
   超过 2V。
5. 新版测试数据应另建表记录，不覆盖本文件中的旧板原始数据。
