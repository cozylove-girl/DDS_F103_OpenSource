# AD8307 双通道测试与直通校准

[实测记录](test.md)来自使用 3.3 V 供电的旧版调理板。本文说明如何测试结题样机的 5 V 双通道调理板，并用旧板数据举例说明如何判断压缩。

## 1. 测试目标

1. 确认两个 AD8307 是否随输入幅度变化保持接近 25mV/dB 的斜率。
2. 确认 REF 与 DUT 两路在相同输入下的固定差异。
3. 确认 AD8307 输出滤波和软件等待时间是否足够。
4. 验证新版 5V 供电与对称输入结构能否改善旧板顶部压缩和通道不一致。
5. 为 RAM 直通多点校准提供可靠数据。

## 2. 旧版与新版差异

### 旧版硬件

- 两个 AD8307 使用 3.3V 供电。
- REF 与 DUT 输入结构不完全一致。
- DUT 通道曾设置 50Ω 对地终端，REF 通道没有。
- OPA690 输出曾串联 50Ω。
- AD8307 输出串联 2kΩ，并带对地电容。

### 结题样机

- 两个 AD8307 均使用 5V 模拟电源。
- REF 和 DUT 输入结构、器件值、输出滤波和布局保持对称。
- 默认不安装固定 50Ω 对地终端。
- 两路输出均经 2.2 kΩ 串联电阻和 100 nF 对地电容滤波。
- REF 采样点位于 OPA690 输出隔离电阻之后。

## 3. AD8307 理论关系

典型对数斜率：

```text
25mV/dB
```

最可靠的相对判断：

```text
输入幅度翻倍 -> 增加约 6.02dB
AD8307 输出应增加约 150mV
```

输入幅度增加 10 倍时，AD8307 输出应增加约 500mV。

5V 供电不会使 AD8307 正常输出接近 5V。它主要改善器件工作和输出摆幅裕量。输入约几百 mVpp
时输出约 2V 可能正常；判断是否压缩应观察输出增量是否仍接近理论斜率。

## 4. 旧版 `test.md` 数据结论

固定 1MHz 时：

| OPA690 输出 | AD8307#1 | AD8307#2 |
|---:|---:|---:|
| 256mVpp | 1902mV | 1912.3mV |
| 632mVpp | 1957.4mV | 1960mV |
| 752mVpp | 1964.4mV | 1966.2mV |
| 992mVpp | 1972.8mV | 1973.2mV |
| 1420mVpp | 1984.6mV | 1982.8mV |

旧板从 256mVpp 增加到 1420mVpp，AD8307 输出仅增加约 80mV，远低于理想对数斜率，说明旧板在
该测试条件下存在明显压缩或输出负载限制。

两路输出几乎相同，也说明旧板 DUT 端 50Ω 终端没有表现出简单 2:1 分压预期。新版不再保留这种
不对称终端结构。

## 5. 新版推荐工作点

调试时在实际频率和接线条件下改变输入幅度，检查两路输出增量是否接近 25 mV/dB。输入幅度翻倍时，预期输出增加约 150 mV。换板后应重新测量有效线性区。

## 6. 新版测试步骤

### 6.1 测试准备

1. 示波器输入设置为 1MΩ，不使用 50Ω 模式。
2. 固定输入为正弦波，首先测试 1MHz。
3. 分别观察 OPA690 输出隔离电阻前、REF/TEST_IN、DUT/TEST_OUT、两个 AD8307 输入与输出、
   PA3 和 PA4。
4. 每次改变幅度后至少等待 120ms。

### 6.2 静态检查

| 测试项 | 预期 |
|---|---|
| AD8307 REF / DUT 供电 | 接近 5V |
| 无输入时 OUT | 两路稳定且接近 |
| OUT 波形 | 无明显高频自激 |
| PA3/PA4 | 不超过 3.3V |

### 6.3 幅度斜率测试

固定 1MHz，逐步设置 REF 节点实际输入幅度：

| REF 实际输入目标 | 与上一档关系 | 理论输出增量 |
|---:|---:|---:|
| 50mVpp | 起始点 | - |
| 100mVpp | 幅度翻倍 | 约 +150mV |
| 200mVpp | 幅度翻倍 | 约 +150mV |
| 400mVpp | 幅度翻倍 | 约 +150mV |
| 600mVpp | 约 +3.52dB | 约 +88mV |

记录：

| 实际输入 | REF OUT | DUT OUT | REF 增量 | DUT 增量 | 判断 |
|---:|---:|---:|---:|---:|---|
| 50mVpp |  |  | - | - |  |
| 100mVpp |  |  |  |  |  |
| 200mVpp |  |  |  |  |  |
| 400mVpp |  |  |  |  |  |
| 600mVpp |  |  |  |  |  |

若输入继续增加但输出增量明显小于理论，应将上一档附近作为推荐上限。

### 6.4 双通道一致性测试

将 REF 和 DUT 接到同一实际信号节点，记录：

```text
delta_mv = DUT_OUT - REF_OUT
```

若差异主要为固定偏移，RAM 直通校准可以有效补偿；若差异随输入幅度明显变化，则两路斜率不同，
需检查器件、负载和输入结构。

### 6.5 频率平坦度测试

选择不会压缩的固定输入幅度：

| 频率 | REF OUT | DUT OUT | 两路差值 |
|---:|---:|---:|---:|
| 100Hz |  |  |  |
| 1kHz |  |  |  |
| 10kHz |  |  |  |
| 100kHz |  |  |  |
| 1MHz |  |  |  |
| 5MHz |  |  |  |
| 10MHz |  |  |  |

低频异常下降时，应检查输入/输出耦合电容形成的附加高通，而不是先修改扫频算法。

### 6.6 输出滤波电容验证

样机使用 100 nF。调试其他电容值时，可对比下表中的预期趋势，并在相同输入条件下记录实际稳定时间。

| 电容 | 预期特点 |
|---:|---|
| 10nF | 响应快，但 ADC 读数可能更抖 |
| 47nF | 响应速度和读数波动介于两者之间 |
| 100nF | 更稳定，但频率切换后需要更长等待 |

两路必须使用相同电容。若 120ms 等待后读数仍持续变化，应增大等待时间或减小输出滤波时间常数。

## 7. 软件直通校准

```text
TEST_IN 与 TEST_OUT 直通
STEP -> NEXT:CAL
按 SWEEP 完成 81 点校准
```

校准完成后：

```text
CORR:ON  -> 普通测量逐点减去校准误差
CORR:OFF -> 显示按两路差值换算的增益，保留固件固定偏移
```

校准只能补偿测量链路误差，不能消除 AD8307 对 LC 网络造成的真实加载，也不能修复已经进入压缩
区的数据。
