# STM32 DDS 固件与接线指南

适用于 `DDS_F103` 工程。引脚和参数对应当前固件，模拟电路见[系统架构](DDS_architecture.md)。

## 1. 项目目标

基于 STM32F103C8T6 和 AD9834，实现：

1. 1Hz 至 10MHz 正弦波、三角波、方波控制。
2. 按键、旋钮和 LCD 人机交互。
3. 100Hz 至 10MHz 自动幅频扫频和曲线显示。
4. 基本滤波器类型与截止频率估算。
5. RAM 多点直通校准、校准开关和上次曲线保存。
6. 外部波形的频率估算和类型识别，显示 ADC 侧峰峰值。
7. 红色插值游标读取曲线数据。

## 2. 开发约束

- MCU：STM32F103C8T6，72MHz，64KB Flash，20KB SRAM。
- 固件使用整数运算和轻量的 LCD 数值格式化。
- 截止频率和类型分析在完整扫频后执行。

## 3. 当前引脚分配

| 功能 | 引脚 |
|---|---|
| LOG_REF | PA3 / ADC1_IN3 |
| LOG_DUT | PA4 / ADC1_IN4 |
| WAVE_ADC | PA5 / ADC1_IN5 |
| AD9834 SPI | PB13 / PB15 |
| DDS_FSYNC / DDS_RST | PB12 / PB14 |
| DDS_FSEL / DDS_PSEL / WAVE_SEL | PB0 / PA7 / PA6 |
| LCD_CS / DC / RST / BLK | PA15 / PA11 / PA12 / PA8 |
| LCD_SCK / MOSI | PB3 / PB5 |
| 编码器 A/B | PB6 / PB7 |
| ENC / MODE / STEP / SWEEP | PB8 / PB1 / PB4 / PB9 |

`BODE_SWAP_REF_DUT = 0` 时，PA3 是 REF，PA4 是 DUT。若实物接反，只修改该配置，不修改扫频算法。

## 4. 软件模块

| 文件 | 当前职责 |
|---|---|
| `main.c` | 初始化和主循环 |
| `bsp_ad9834.c` | AD9834 频率和波形控制 |
| `bsp_adc_dma.c` | BODE 单通道轮询、PA5 TIM3+DMA 采样和模式切换 |
| `bsp_input.c` | 编码器与按键事件 |
| `bsp_lcd_ili9341.c` | LCD 绘图和轻量数值格式化 |

| `app_sweep_plot.c` | 扫频、绘图、分类、截止频率、校准和游标 |
| `app_ui.c` | 页面和按键行为 |
| `project_config.h` | 全局参数和阈值 |

主循环保持：

```text
while (1):
    UI_Task()
    ADC_Task()
```

耗时测量由状态机和 DMA 回调推进，不在主循环中加入长时间阻塞。

## 6. BODE 开发规则

### 6.1 正常测量流程

```text
设置 DDS 正弦波和当前频点
-> 等待稳定
-> 三轮读取 REF/DUT
-> 每轮内部平均 96 次
-> 三轮结果取中值
-> 应用可选校准补偿
-> 保存并绘制
-> 进入下一频点
-> 81 点完成后分析
```

### 6.2 当前已实现功能

- 完整 81 点对数扫频。
- 曲线显示范围约 -80dB 至 +20dB。
- LPF / HPF / BPF / PK / UNK 分类。
- 基于稳定平台或峰值连续区域的 -3dB 截止频率估算。
- RAM 多点直通校准。
- `CORR:ON/OFF` 补偿切换。
- 上次结果保留与重新绘制。
- 每扫频点四分之一间隔的红色插值游标。

## 7. 外部波形识别开发规则

### 7.1 当前识别流程

1. 采集 1024 点。
2. 求平均值并去除 DC 偏置。
3. 使用带滞回上升过阈值事件估计频率。
4. 计算 AC VPP、RMS 和削顶状态。
5. 使用峰值因数识别方波。
6. 使用平均绝对幅度比例区分正弦和三角。
7. 模糊区使用峰值因数和曲率辅助判断。
8. 信息不足时显示 `UNK`，不强制误判。

### 7.2 当前阈值

| 波形/特征 | 当前范围 |
|---|---|
| 方波峰值因数 | 0.900 至 1.150 |
| 正弦峰值因数 | 1.280 至 1.560 |
| 三角峰值因数 | 1.600 至 1.950 |
| 三角平均绝对幅度比例 | 小于等于 0.555 |
| 正弦平均绝对幅度比例 | 大于等于 0.590 |
| 模糊区 | 0.555 至 0.590 |

正弦与三角峰值因数窗口不得再次设置为重叠。

### 7.3 硬件边界

外部通道使用约 22 kΩ / 10 kΩ 固定衰减，模拟输入设计范围为 0.1 Vpp 至 5 Vpp。该衰减比约为 0.3125，低幅输入在 ADC 端的摆幅较小，识别受噪声、模拟带宽和固件阈值影响。屏幕的 `VPP` 直接显示 ADC 侧峰峰值。

## 8. 样机调理板

- OPA690、两个 AD8307 使用 5V 模拟电源。
- OPA690 单电源偏置约 2.5V，同相交流增益约 2。
- REF 点位于 OPA690 输出隔离电阻之后。
- REF/DUT 两路 AD8307 输入、输出结构保持对称。
- 默认不安装固定 50Ω 对地终端。
- AD8307 输出经过 2.2 kΩ 串联电阻和 100 nF 对地电容滤波。
- OPA2354A 缓冲 1.65V，OPA2354B 调理外部输入。
- PA5 默认不安装较大对地电容。
- OPA690 输出耦合网络的低频截止必须远低于待测 RC 低通截止频率。

## 9. UI 与按键

当前有效页面为主页面、BODE 页面、外部识别页面。

| 操作 | 主页面 | BODE 页面 | 外部识别页面 |
|---|---|---|---|
| 旋钮 | 调 DDS 频率 | 有结果时移动游标 | 调 DDS 频率 |
| ENC | 切步进 | 切 CORR 开关 | 切步进 |
| STEP | 切波形 | 切 NEXT:MEAS/CAL | 切波形 |
| MODE | 进入 BODE | 进入外部识别，扫频中按下会先中止扫频 | 返回主页面 |
| SWEEP | 启动普通扫频 | 执行 MEAS/CAL，扫频中按下会中止扫频 | 启动普通扫频 |
