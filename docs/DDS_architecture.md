# DDS 信号发生与幅频测试系统架构

本文描述样机的信号路径和当前固件行为。调理板器件值按结题样机的硬件设计记录整理。

## 1. 系统组成

系统以 STM32F103C8T6 为主控，包含四条主要链路：

1. DDS 信号发生：STM32 -> AD9834 -> 输出选择 -> OPA690 -> 待测网络。
2. 幅频特性测量：待测网络输入/输出 -> 双 AD8307 -> PA3/PA4。
3. 外部波形识别：外部 SMA -> OPA2354 调理 -> PA5 ADC/DMA。
4. 人机交互：ILI9341 LCD、旋转编码器和四个按键。

## 2. 当前核心硬件

| 模块 | 当前作用 |
|---|---|
| STM32F103C8T6 | DDS 控制、ADC 采样、扫频、算法、LCD 和按键 |
| AD9834 | 输出正弦波、三角波和方波，MCLK 为 75MHz |
| SN74LVC1G3157 或等效器件 | 切换模拟波形路径与方波路径 |
| OPA690 | 放大 DDS 信号并驱动待测网络 |
| AD8307 × 2 | 分别检测 REF 与 DUT 幅度 |
| OPA2354 | 一路缓冲 1.65V 偏置，一路调理外部波形 |
| ILI9341 | 显示 DDS 设置、幅频曲线和外部识别结果 |

## 3. 模拟信号路径

### 3.1 DDS 信号源

```text
AD9834 DAC 输出
  -> 200Ω 对地负载/电流电压转换
  -> 重建滤波器
  -> DDS 输出 SMA
```

这里的 200Ω 不是 50Ω 终端匹配电阻，不应因为使用 SMA 线而改为 50Ω。

### 3.2 OPA690 放大与驱动

```text
DDS_IN SMA
  -> 输入交流耦合
  -> OPA690 同相输入，偏置在 VBIAS_2V5
  -> 同相交流增益约 2 倍
  -> 宽带输出隔直
  -> 小阻值输出隔离电阻
  -> REF / TEST_IN 节点
```

样机反馈网络：

```text
OPA690 OUT -> Rf=499Ω -> IN-
VBIAS_2V5  -> Rg=499Ω -> IN-
```

`Rg` 必须接 `VBIAS_2V5`，不能接地，否则直流偏置也会被放大并导致削顶。

OPA690 和两个 AD8307 使用 5 V 模拟电源。样机的 OPA690 输入、输出均通过 22 µF 与 100 nF 并联的电容组交流耦合，输出再经过 22 Ω 隔离电阻。更改耦合电容或负载时，应检查低频响应。

### 3.3 待测网络与 SMA

核心 SMA 接口共四个：

| 接口 | 用途 |
|---|---|
| DDS_IN | DDS 板输出进入调理板 |
| TEST_IN | OPA690 输出连接待测网络输入 |
| TEST_OUT | 待测网络输出返回调理板 |
| EXT_WAVE_IN | 外部波形进入 OPA2354 调理通道 |

REF 采样点必须位于 OPA690 输出隔离电阻之后，即测量待测网络实际输入节点。

SMA 线的 50 Ω 是特性阻抗。样机的调理板在 TEST_IN、TEST_OUT 和 AD8307 输入端均未安装固定的 50 Ω 对地终端。

### 3.4 双 AD8307 检测

```text
REF 节点 -> AD8307_REF -> 输出低通 -> PA3
DUT 节点 -> AD8307_DUT -> 输出低通 -> PA4
```

两路必须保持器件值和布局对称：

- 两个 AD8307 均使用 5V 供电。
- 默认不安装固定 50Ω 对地终端。
- 输入端使用无极性 22 µF 与 100 nF 并联耦合。
- 两路输出端均经过 2.2 kΩ 串联电阻和 100 nF 对地电容滤波后进入 ADC。

AD8307 输出约 2V 不代表 5V 供电无效。5V 主要改善工作和输出摆幅裕量，不会使正常对数输出接近
5V。

### 3.5 OPA2354 外部波形通道

OPA2354 使用 3.3V 供电：

```text
OPA2354A:
3.3V -> 10k/10k 分压 -> 对地滤波 -> 电压跟随 -> VBIAS_1V65

OPA2354B:
EXT_WAVE_IN -> 22k 串联
            -> 节点经 10k 接 VBIAS_1V65
            -> 电压跟随/缓冲
            -> 小串联电阻
            -> PA5
```

22k/10k 固定衰减约为：

```text
10 / (22 + 10) = 0.3125
```

外部交流输入按 0.1 Vpp 至 5 Vpp 设计。低幅信号在 ADC 端可能低于固件识别门槛。PA5 默认不并联较大电容，以保留三角波的高次谐波。

## 5. 当前软件实际逻辑

### 5.1 DDS

- 控制范围：1Hz 至 10MHz。
- 支持 SINE、TRI、SQ。
- BODE 扫频期间 DDS 由扫频状态机控制，旋钮不会手动改频。
- 扫频完成或中止后恢复用户 DDS 设置。

### 5.2 BODE

- 扫频范围：100Hz 至 10MHz。
- 点数：81 点，近似对数分布。
- 首点等待 1500 ms，后续点等待 120 ms。
- 每轮对 REF/DUT 各平均 96 次；每个频点执行三轮并取中值。
- 扫频始终完整执行，不因截止点或斜率提前终止。
- 支持 LPF、HPF、BPF、PK、UNK 基本分类。
- 支持截止频率估算、RAM 多点直通校准、CORR 开关和红色插值游标。
- 上次扫频结果保存在 RAM，重新进入 BODE 页面时先重绘，不立即重新扫频。

### 5.3 外部波形识别

- PA5 使用 1024 点 ADC/DMA 快照。
- 采样率档位：20kS/s、100kS/s、600kS/s。
- 先去除 DC 偏置，再计算 VPP、RMS 和频率。
- 方波优先使用峰值因数判断。
- 正弦/三角使用平均绝对幅度比例作为主判据，峰值因数和曲率作为模糊区辅助判据。
- 当前正弦和三角峰值因数窗口不重叠。

## 6. 当前有效 UI 页面

当前正式保留三页：

1. 主页面：DDS 设置和上一次 BODE 摘要。
2. BODE 页面：测量、校准、曲线、分类、截止频率和游标。
3. 外部波形识别页面：左侧 DDS 调节，右侧 WAVE / FIN / VPP / WARN。

测试页和自检预留页面已删除，以节省 Flash。

## 7. 当前限制

- 纯 LC 网络的峰值和带宽会受源/负载阻抗影响。
- 外部输入固定单量程兼容 5Vpp 后，0.1Vpp 输入的正弦/三角识别仍较困难。
- PA5 的最高采样率为 600 kS/s，对应 300 kHz 奈奎斯特频率。波形分类还依赖每周期采样点和模拟通道保留的谐波，实际可用范围随幅度与波形而变。
- 校准和上次曲线只保存在 RAM，断电丢失。
